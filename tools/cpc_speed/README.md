# Темп оригинала CPC без окна

CPCBox (JavaScript-эмулятор Amstrad CPC с amstrad.retrogamecoders.com,
чужой код, в репозиторий не входит) + `cdt.js` — наша добавка: лента
CDT/TZX разворачивается в тот же поток уровней 125 кГц, который CPCBox
получает из WAV. `bench.js` гоняет страницу в puppeteer без окна и без
звука: набирает `|TAPE`, `RUN"`, жмёт PLAY, загружает ленту (358 с
эмулированного времени, ~40 с реального), проходит заставку и меню
(пробел, «1» ~1 с — матч стартует сам) и считает входы в главный цикл
`02A3` (аналог MSX `8554`) за 2,4..12,4 с после первого входа, как
`msxspeed_*.tcl` для MSX. Кадры матча — `build/cpcbox/<режим>_t*.png`.

    tools/cpc_speed/run.sh still     # стоя: 70 → 7,0 Гц (пауза после корзины внутри окна)
    tools/cpc_speed/run.sh motion    # бег вправо 3,4 с: 65 → 6,5 (с 11 с идёт повтор)

В чистой игре CPC даёт ≈ 7,5 итерации в секунду (медиана интервала
0,131–0,140 с). Эмулятор детерминирован: повторы дают те же числа.
`fetch_cpcbox.sh` скачивает CPCBox в `build/cpcbox` и выключает автостарт
сайта (он перезапускал машину через 2 с). Нужны `node` и глобальный
`puppeteer` (`npm root -g`).

Почему не MAME: на CPC6128 перехват чтения по адресу слетает при
переключении банков, точка `02A3` срабатывала два раза за матч.
