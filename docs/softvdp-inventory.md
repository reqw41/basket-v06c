# Soft VDP: снят (04.11)

ROM `629bb468a2feb4c5f502fc260290d915b8769000b86fa69a81d70cb8f76a9f33`.

MSX-слой эмуляции видеопроцессора (OUT 98h/99h, IN 98h/99h, регистры,
статус, SET_VBLANK) удалён. Всё изображение пишется прямо в две плоскости
Вектора. Гейт `python3 tools/inventory_softvdp_v06.py` (в verify_refactor)
падает, если какой-либо сценарий исполняет RST 08/10/20/28 или в образе
появляется новая пара «RST + NOP» кроме двух известных данных (3418 —
операнд JP D77E в старой таблице переходов, 3488 — байт таблицы).

| Было | Стало |
|---|---|
| штамп «вставших» A521 → MSX-картинка на экран | CPC-штамп 264A как состояние фона (BG_FETCH B338) |
| AFC8: MSX-табло блиттером поверх меню | убрано, табло — HUD_DECOR |
| 9F48 полоса силы: только нижняя плоскость | обе плоскости, сплошная, перерисовка в HUD_TEXT_REFRESH |
| 8AAE значок мяча через D252 | CPC-спрайты 72/73, HUD_ICON B455 |
| A0BF шторка: OUT 99h/98h, A132 — таблица цветов | A0D0 прямой столбец из BG_FETCH, A132 = RET |
| D252/D241/D247/D24C VRAM-блиттер 34BD | сдвиг указателя 3302 (все записи и так отбрасывались) |
| ISR 36F5 / init 35C1: статус VDP | LD A,80h / удалено |
| 3760: запись R1 | RET |
| RST 08/10/20/28, SOFTVDP_*, SET_VBLANK | RET / удалено, место — нули |
| мёртвые 359C..35BF, A8FB..A95D, B201..B233 | обнулены сборщиком |

RST 18 остаётся: это MSX BIOS OUTDO, у нас — вызов игровой печати глифов
(D8EB → 3B53), не видеопроцессор.

Освобождено (нули, доступно под код): 033F..040A (204 Б, перед
FRAME_END), 0292..0299, 1748..1763, 1844..1850, A524..A52B, 359C..35BF,
A8FB..A95D, B201..B233.
