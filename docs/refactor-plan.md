# План рефакторинга: память и четыре цвета

Цель: перейти от текущего монохромного Z80-порта с MSX-адресами к
бюджетной раскладке Вектора и режиму 2+2 (четыре пера). Этап 0 —
только контрольная точка; игровая логика на нём не меняется.

Каждый этап ниже — **отдельный коммит**. Не начинать следующий, пока
текущий не зафиксирован и проверки не обновлены вместе с адресными
контрактами.

## Целевая карта памяти (бюджеты этапа 1+)

Это **целевые** диапазоны для подтверждения на этапе 1, не текущая
раскладка (`docs/v06-memory.md`). Прежнее ограничение всего кода
диапазоном `84D0..B257` снимается.

| Диапазон | Размер | Назначение |
|---|---:|---|
| `0000..01FF` | 512 | Системные входы и загрузка |
| `0200..3FFF` | 15.5 КБ | Весь код |
| `4000..4FFF` | 4 КБ | Отдельный резерв под перекомпиляцию i8080 |
| `5000..9FFF` | 20 КБ | Графика, маски, шрифты, музыка |
| `A000..A3FF` | 1 КБ | Общий резерв |
| `A400..AFFF` | 3 КБ | Состояние и служебные данные |
| `B000..B3FF` | 1 КБ | Стек |
| `B400..BFFF` | 3 КБ | Графические буферы обеих плоскостей |
| `C000..DFFF` | 8 КБ | Видеоплоскость 0 |
| `E000..FFFF` | 8 КБ | Видеоплоскость 1 |

## Этапы

| # | Этап | Суть | Коммит (ожидание) |
|---|---|---|---|
| 0 | Контрольная точка | Воспроизводимый ROM, `verify_refactor`, документация baseline/plan | `chore: establish reproducible refactor baseline` |
| 1 | Бюджет | Подтвердить вместимость по целевой карте; инвентаризация размеров без переезда логики | `docs: define validated memory layout and budgets` |
| 2 | Игровые проверки | Закрыть/задокументировать FAIL `match_1p_esc` и `match_replay`; усилить сценарии | отдельный |
| 3 | Адресные зависимости | Каталог абсолютных адресов, обновление контрактов тестов | отдельный |
| 4 | Компактный рендеринг | Ужать compose/dirty/court path под новые буферы | отдельный |
| 5 | Ресурсы | Перепаковка графики, масок, шрифтов, музыки в `5000..9FFF` | 05.11: пустые строки спрайтов обрезаны (−2181 Б), ресурсы 19194 ≤ 20480 |
| 6′ | Символьные адреса | 05.11: вместо ручного переезда Z80-образа — адреса игры и входы адаптера по именам (`cfg/labels.json`, гейт `test_labels.py`), итоговая карта в [target-layout.md](target-layout.md); переезд — при перекомпиляции | сделано |
| 7 | Четыре цвета | Режим 2+2, палитра ≈ CPC, обе плоскости | отдельный |
| 8 | Оптимизация | Циклы кадра, размер, запас под i8080 в `4000..4FFF` | отдельный |
| 9 | Приёмка | Полный профиль `verify_refactor` + ручной playthrough | отдельный |

## Правила между этапами

- Не ослаблять проверки ради зелёного статуса; FAIL фиксировать явно.
- При переносах обновлять адресные контракты тестов вместе с кодом.
- Рабочий ROM и отчёты `build/verification/` в Git не коммитить.
- Рекомпиляция Z80→i8080 — после живого эталона на новой раскладке
  (см. [plan.md](plan.md), [recompilation.md](recompilation.md)).
