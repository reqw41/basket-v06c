## Изменения

- Пересечение каждого staged-объекта с буфером вычисляется один раз; внутренний цикл обрабатывает только пересекающиеся строки/столбцы. После пропущенного объекта указатель источника всё равно проходит весь его поток.
- Цветная подложка классифицируется один раз на строку. Два указателя идут напрямую по источнику и готовому буферу вместо сохранений стека и вызова классификатора на каждый байт. Результат проверен против прежнего классификатора для всех 112 строк, 32 столбцов, четырёх низких байтов и обоих типов сцены.
- Близкие игроки собираются в один прямоугольник при ширине до 8 байтов и размере до 1280 байтов. Это исключает показ части нового второго игрока внутри старого кадра при отдельной публикации пар в проверенном сценарии пересечения. Широкие/большие объединения сохраняют прежний раздельный путь; улучшение для любых возможных больших пересечений этим этапом не доказано.
- Растровая проверка учитывает настоящую окклюзию: поздний игрок закрывает раннего. Она всё равно требует все открытые пиксели цельного тела/головы; меню проверяется отдельно.

## Память

Новые процедуры заняли прежний нулевой хвост меню, без расширения спрайтового банка или рабочего буфера:

| Диапазон, включительно | Назначение |
|---|---|
| 1950..1A45 | отсечение и смешивание staged-объектов, 246 байт |
| 1A46..1A51 | 12 частных рабочих байтов, IRQ отключены |
| 1A52..1A5F | 14 сохранённых нулевых байтов между фиксированными входами |
| 1A60..1ABF | выбор общего буфера, 96 байт |
| 1AC0..1B12 | классификация строки фона, 83 байта |
| 1B13..1B3F | оставшиеся 45 нулевых байтов меню |

Старый цикл композиции B105..B16B заменён переходом; этот нулевой промежуток сохранён для стабильности адресов публикации. Это не новая заявка на свободную память. Replay ring по-прежнему начинается с 1B40, статический фон с 2500. Карта и бюджет привязаны к новому SHA; будущая целевая карта/резерв рекомпиляции этим этапом не объявлены достигнутыми.
