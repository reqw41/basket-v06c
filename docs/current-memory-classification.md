# Полная классификация текущей памяти

Эта карта относится к ROM
`0ec80f8940f5a4e595977ae957d5b7a047216e18087f57d86be2beadaf3c62ea`
(звук и заставка CPC, цветное меню, исправленный повтор; 04.11.2026). Машиночитаемый контракт —
`cfg/current_memory_map.json`; подробности меню/баннера —
[cpc-text-menu-vector.md](cpc-text-menu-vector.md).

Машиночитаемый контракт находится в `cfg/current_memory_map.json`.
Команда `python3 tools/classify_memory_v06.py` объединяет его с CFG,
абсолютными ссылками, SMC и трассами только от ROM с тем же SHA-256. Результат
записывается в `build/v06/memory_classification.json`. Проверка требует ровно
65536 классифицированных байтов без дыр и пересечений.

## Смешанные области

`84D0..B257` полностью покрыта следующими классами:

| Класс | Байты | Правило |
|---|---:|---|
| обычный CFG-код | 9961 | декодирован из доказанных входов |
| self-modifying code | 10 | CFG-код, в который есть записи |
| mutable state | 194 | запись замечена matching-ROM трассой |
| referenced data | 259 | чтение в трассе или статическая ссылка |
| opaque retained | 1232 | более узкая семантика не доказана; байты сохраняются |

Перенесённая область `3304..3F7F` также покрыта полностью:

| Класс | Байты |
|---|---:|
| обычный CFG-код | 1275 |
| self-modifying code | 22 |
| mutable state | 23 |
| referenced data | 297 |
| opaque retained | 1579 |

`opaque retained` не означает «неизвестно, можно удалить». Это точный класс
безопасности: байт принадлежит загруженному объекту, его более узкое назначение
не доказано, поэтому переносчик обязан сохранить его и его адрес. В целевую
секцию code/resources/state такие байты нельзя зачислять до появления символа,
дизассемблированного объекта или трассы.

## Что действительно можно освободить

Доказаны четыре промежутка: `0DFF` (1 байт), `7B9C` (1), `84C3..84CF` (13) и `B331..B337` (7).
Всего **219 байт**. Бывший AY-слот частично занят генератором цвета корта,
а интервал `808A..84CF` содержит 904 байта двухплоскостного HUD и 135 байт
потокового кода.
Остальные прежние свободные интервалы были
использованы для переноса корта и system/HUD-блока, чтобы предоставить
аппаратной плоскости непрерывные `C000..DFFF`.
Для каждого свободного промежутка проверяются ожидаемое содержимое, отсутствие
CFG-кода, типизированных статических ссылок, SMC и обращений во всех
matching-ROM трассах.

Значения `0A0D`, `0B07`, `0C00`, `0C0C`, из-за которых раньше сохранялся
первый диапазон, оказались парами игровых координат в `LD HL,nn`. Они
передаются процедурам позиционирования и не разыменовываются как адреса.

Классификация доказывает полноту карты текущего образа. Она не доказывает, что
все игровые ветви были исполнены, и не превращает `opaque retained` в свободное
место. Новая трасса может только уточнить класс; проверка не разрешает молча
занять сохраняемые байты.
