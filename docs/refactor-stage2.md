# Этап 2: игровые сценарии

Этап закрывает два прежних FAIL полного профиля без записи PC, SP или игровых
флагов из тестов.

## Выход из матча

Игра проверяет `SHIFT+CTRL+ESC` в `L_8685` через `D5DE`. Порт переносил ESC,
но принудительно оставлял биты SHIFT/CTRL строки MSX 6 отпущенными. Теперь
`V_KBD_POLL` читает физические модификаторы Vector из старшей половины PPI-C и
переносит их в MSX row 6. Сценарий нажимает реальную комбинацию и наблюдает
возврат в меню.

## Естественный повтор

Предыдущий сценарий управлял стрелками, которые являются раскладкой второго
игрока. В режиме 1P человек использует сохранённую игрой раскладку
`1/Q/D/F/Z`; второй игрок управляется AI. Сценарий теперь ведёт первого игрока
в окно броска `L_8F0F` этими клавишами. Игра сама выставляет `93D3`, начисляет
бросок типа 4 и входит в `REPLAY_ZOOM`.

`tools/test_game_flow.js` дополнительно ждёт полного завершения повтора,
продолжения матча и проверяет отображение физического аккорда в строках MSX.
`tools/test_replay_zoom.js` остаётся проверкой восстановления HUD/площадки и
графических процедур.

```sh
python3 tools/verify_refactor.py --profile full
```
